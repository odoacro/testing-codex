# testing-codex

Este repositorio es un entorno de pruebas utilizado para experimentar con 
flujos de trabajo de Git y GitHub.

## Objetivo

Permitir la práctica segura de commits, ramas y herramientas automatizadas sin 
afectar a un proyecto real.

## Cómo usarlo

1. Clonar el repositorio.
2. Realizar cambios en los archivos o agregar nuevos.
3. Ejecutar las pruebas o comandos necesarios para validar los cambios.
